# Omnicart Tycoon

Omnicart Tycoon is an interactive e-commerce simulator from Vedøy Studio. Build a store, choose products and suppliers, manage inventory and orders, and grow from a small shop into a larger retail business.

## Live beta

Play the latest deployed beta at [omnicart-tycoon.vedoystudio.no](https://omnicart-tycoon.vedoystudio.no/).

Project page: [Vedøy Studio — Omnicart Tycoon](https://www.vedoystudio.no/projects/omnicart-tycoon)

## What you can practise

- Product, supplier and collection choices
- Inventory, orders and margins
- Monthly operating costs
- Marketing and growth scenarios
- Store strategy and retail decision-making

## Status

Beta — version `0.1.0`.

The public deployment is currently managed through Vercel. This repository is the project home for documentation and future source releases.
